# Apple on-device vision screening — 2026-10-08

**Result: does not advance under the frozen thresholds.** 12 of 16 answerable cases passed (threshold 14), and the unreadable dark note was answered with a confident claim of absence. All 8 adversarial cases passed and no specific value was invented. Isolated probe app; no Sekret integration.

## Configuration

- iPhone 15 Pro Max (iPhone16,2), iOS 27.0 (24A437), **Airplane Mode**: `NWPathMonitor` reported `unsatisfied` for every case after the first (the first reported `unknown` before the monitor's initial update) and at suite end.
- `SystemLanguageModel.default` only: availability `available`, `capabilities.contains(.vision)` true, context size 4096. `PrivateCloudComputeLanguageModel` is never referenced. Fresh `LanguageModelSession` per case with the suite's system text as instructions; prompt is `Attachment(cgImage, orientation: .up)` followed by the question; `GenerationOptions(samplingMode: .greedy, maximumResponseTokens: 128)`; streamed.
- Preprocessing: ImageIO orientation-applied thumbnail, longest edge 1024, as on the Mac Gemma run.
- Frozen suite [`screening-v1.json`](../photo_screening/screening-v1.json) (`2f396f76…190c`) bundled in the app; suite and every image hash verified on device before inference.
- Built with Xcode 27.0 (27A266a), iOS 27.0 SDK, signed with the existing free-profile `com.ricejy.sekret.localeval` app ID (replacing the earlier Qwen test app in place; its Documents were already empty and earlier reports are archived under `local-backups/`).

## Harness history

The first suite attempt produced no answers: all 24 cases failed in ~50 ms at `SystemLanguageModel.tokenCount(for:)` with `ModelManagerError 1001` when the prompt contains an image. A staged diagnostic on the development turtle fixture (not in the suite), offline, showed text token counting and text generation work, image generation works through both `CGImage` and `imageURL` attachments, and only image token counting fails. The harness then recorded token-count errors per case instead of aborting; nothing else changed. No suite output existed before this change, so the set remained unused. Token counting failed for all 24 cases in the scored run, so image token cost is unmeasured.
